# Repository guidance

To connect a Mac to a remote VM (first time, another VM, or a VM that cannot be
added), read `.agents/skills/rws-vm-onboarding/SKILL.md`. The VM-side prerequisites
are checked by `rws onboard check`; never install or configure them for the person.

For installing, configuring, or troubleshooting RWS on a new Mac, read
`.agents/skills/rws-macos-setup/SKILL.md` and follow its evidence-based setup workflow.
Keep personal configuration and screenshot originals in the Git-ignored
`.rws-local/` directory. Consult `docs/validation.md` before claiming a workflow
has been validated end to end.
