# Simple connection implementation plan

**Goal:** deliver reusable connection settings, safe repeatable lifecycle commands,
double-click shortcuts, and an evidence-based account of Delta remote execution.

**Architecture:** retain the existing Rust CLI and SSHFS startup manager. Add a
lifecycle module for mount-table identity and receipts, a bounded SSH probe, and
shortcut generation. Keep personal configuration in `.rws-local/`.

**Constraints:** preserve old configuration and commands; no forced unmount,
no changes to the active Delta worktree, no silent local execution fallback.

- [x] Add CLI regressions for remembered mount options, disconnected status,
  repeat disconnect, shortcut quoting and errors; run them failing.
- [x] Implement saved global mount settings through the existing atomic config
  writer. Add `settings --sshfs PATH --backend fskit|default`.
- [x] Implement `connect`, `disconnect`, `status`, and `shortcuts`. Identify
  mount instances with macOS nonblocking mount-table snapshots and persist a
  receipt after successful startup; reject foreign or unverifiable instances.
- [x] Cover receipt identity changes and absent/foreign mounts in unit tests.
  Check SSH probes have a hard deadline and never run a workload locally.
- [x] Generate exclusive, executable `.command` files using absolute CLI and
  config paths, shell quoting, error reporting and a final key prompt.
- [x] Inspect Delta remote execution support independently; document findings
  and do not claim its commands are remote without a Delta-originated probe.
- [x] Run locked tests, format, Clippy; review implementation and address
  findings. Run an isolated real connect/write/SSH/disconnect cycle, including
  repetitions and independently verified remote files.
- [x] Save local user settings and shortcuts; update prototype and validation
  documentation with results and outstanding integration limitations.

Final evidence: 34 local automated tests, format and Clippy pass; two real isolated mount cycles, busy refusal, wrong-destination refusal and generated remote shell verified. See docs/validation.md. Delta engine remains local; no supported SSH backend was found.
